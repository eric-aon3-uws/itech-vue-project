# Vue.js Presentation Website (itech-vue-project)

This website was developed in order to host the materials made for Group G's presentation on **Vue.js** during 26/27's run of the **Internet Technologies** module.

**Live site:** https://eric-aon3-uws.github.io/itech-vue-project/

## Website Structure

The website's content is divided between seven pages: **Home**, **Presentation**, **Notes**, **Cheat Sheet**, **Setup Tutorial**, **Development Tutorial** and **Live Demo**.

### Home

**Home** contains a brief description of the presentation's topic and the group members, and links to the rest of the site.

### Presentation

**Presentation** contains all the slides used during the presentation, together with some of the members' script notes used during the presentation, which are also annotated with their names for attribution.

### Notes

**Notes** is a written reference on Vue.js to read alongside the presentation: what Vue is, a short history, core concepts, how Vue fits into a full web application, the ecosystem (Vite, Vue Router, Pinia, Nuxt), a comparison with React, Angular and Svelte, pros and cons, and when to use it. All claims are referenced (Harvard style).

### Cheat Sheet

**Cheat Sheet** is a quick syntax reference for Vue 3 with the Composition API: project commands, template syntax, reactive state, components, Vue Router, Pinia and common beginner mistakes.

### Setup Tutorial

The **Setup Tutorial** page guides you through setting up a Vite + Vue.js project inside a Docker dev container, so it works on UWS machines without installing Node.js. It includes the Vite settings needed for live reload inside Docker. It is then continued in **Development Tutorial**.

### Development Tutorial

The **Development Tutorial** picks up from where the **Setup Tutorial** left off, showing you how to build a Paisley Christmas Market website step by step using reactivity, components, props, list rendering, `v-model` and computed values.

### Live Demo

**Live Demo** runs the finished Paisley Christmas Market app inside the site. Students can switch between the tutorial steps to compare their own app with the expected result, and watch the app's reactive state change live.
